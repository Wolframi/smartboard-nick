# SmartBoard

Доска задач. Регистрация по никнейму. В аватарке — первые две буквы ника. При запуске сервер сам определяет IP компьютера в сети.

## Запуск

Нужен [Node.js](https://nodejs.org/) 18 или новее.

```bash
git clone <ссылка-на-репозиторий>
cd SmartBoard-nick
npm install
npm start
```

В консоли появятся адреса:

- `http://localhost:3000` — только на этом ПК
- `http://192.168.x.x:3000` — для других компьютеров в той же сети (этот адрес откройте в браузере)

Регистрация привязана к IP клиента, поэтому заходите по сетевому адресу из консоли, не через `localhost`.

Порт по умолчанию: `3000`. Чтобы сменить: скопируйте `.env.example` в `.env` и укажите `PORT`.
